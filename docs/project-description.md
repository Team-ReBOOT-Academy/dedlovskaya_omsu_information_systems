# Сервис торговой стратегии
---
## Для чего нужен?
Сервис торговой стратегии разработан как помощник инвесторам, призванный на основе полученных данных выдавать торговые рекомендации: стоит ли купить или продать ценные бумаги.
---
## Цель проекта
На данный момент цель данного проекта заключается в разработке сервиса, способного анализировать рынок ценных бумаг и выдавать рекомендации.
